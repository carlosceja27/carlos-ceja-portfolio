# Carlos Ceja — Communication Portfolio

Senior Capstone Portfolio (`COMM 197`) for **Carlos Ceja** — B.A. Communication Studies (Organizational Communication, Class of Fall 2026) at Santa Clara University, U.S. Army Veteran, and Design Program Manager.

- **Live Portfolio:** [https://carlosceja27.github.io/carlos-ceja-portfolio/](https://carlosceja27.github.io/carlos-ceja-portfolio/)

## Features
- **Interactive Competency Filter Bar:** Filter all 6 capstone artifacts across the 7 SCU Department of Communication core competencies with live screen-reader announcements (`aria-live="polite"`).
- **Light & Dark Theme:** Persistent theme toggle (`localStorage`) meeting WCAG 2.1 AA contrast standards across both palettes.
- **Unified Presentation Mockups:** Responsive WebP project cards (16–28 KB each) with device framing and zero external JavaScript dependencies.
